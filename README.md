# Guess the Number Game

Guess the Number is a simple and interactive web-based game where players try to guess a randomly generated number between 1 and 100.

📖 How It Works
Click the Start button (or begin guessing) to generate a random number between 1 and 100.
Enter your guess and click Guess or press Enter.
The game provides hints after each attempt:
Too High! – Your guess is greater than the target number.
Too Low! – Your guess is less than the target number.
The game keeps track of all your guesses and the number of attempts.
When you guess the correct number, a success screen displays:
The correct number.
Total attempts taken to solve the game.
A history of all guesses made.
Click Play Again to start a new game with a new random number.
